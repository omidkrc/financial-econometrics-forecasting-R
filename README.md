# Financial Econometrics in R: Unit Root, ARMA, FI-GARCH, and VaR Modeling

This repository contains translated, cleaned, and reproducible reports for three R-based projects from a Financial Econometrics course.

The projects cover classical and advanced time-series methods, including ADF unit-root testing, HEGY seasonal unit-root testing, SARIMA modeling, ARMA mean-equation modeling, FI-GARCH volatility modeling, and Value-at-Risk forecasting.
